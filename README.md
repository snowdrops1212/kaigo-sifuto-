# あかり シフトプランナー

介護施設向けの月間シフト作成・調整ツールです。ブラウザー内のメモリーで動作し、データは画面上部の「データを保存」「データを開く」で JSON として受け渡します。

## 構成

- `dist/engine.js` — シフトデータ、検証、作成ロジック
- `dist/conditions.js` — 施設条件の文章生成と解析
- `dist/app-core.js` — 共通状態、DOM補助、履歴、画面切り替え
- `dist/app-requests.js` — 希望休・有給・出勤希望、会議日、対象月条件
- `dist/app-schedule.js` — シフト表、人数集計、セル編集
- `dist/app-members.js` — 職員、個別条件、施設条件
- `dist/app.js` — 起動処理、保存・読込、CSV、キーボード操作
- `dist/style.css` / `dist/requests.css` — 共通表示と希望登録画面の表示

JavaScript は `dist/index.html` に記載された順番で読み込みます。各UIファイルは同じブラウザー状態を共有するため、順番を変更する場合は全テストを実行してください。

## ローカル起動

```powershell
python -m http.server 8766 --bind 127.0.0.1 --directory dist
```

ブラウザーで `http://127.0.0.1:8766/` を開きます。

## テスト

```powershell
Get-ChildItem -Filter 'test*.cjs' | Sort-Object Name | ForEach-Object { node $_.FullName }
```

テストはシフト生成、配置人数、希望、会議日、有給期間、職員削除、画面構成、保存データ互換性を確認します。

## 固定の勤務ルール

- Aは使用しません。
- B（日勤）は人数制限なし、C（遅番）は毎日ちょうど2人、D（夜勤入り）は毎日ちょうど1人です。
- Iは職員情報で「パート」かつ「I勤務を使用する」にした職員専用の日勤（9:00〜17:00、7時間）です。
- 管理者は正社員・I勤務なしで登録し、会議日はB（日勤）を強制設定します。
- I勤務者は月9日以上のE（休日）を確保し、個別に入力した月間時間ではなく月の日数から自動計算します。
- 旧JSONに雇用区分とI勤務設定がない職員は、正社員・I勤務なしとして読み込みます。

## 有給期間

- 職員情報の入職日から6暦月後を、最初の有給利用開始日として自動計算します。
- 入職日から6か月間は有給を登録できません。
- 初回開始日から1年間を1周期とし、以後も職員ごとの同じ周期で集計します。
- 月末日が存在しない場合は、その月の末日に丸めます（例：8月31日の6か月後は2月末日）。
- 入職日を変更すると期間表示と集計は自動で再計算されます。

## データ取り扱い

- 入力内容はブラウザーを閉じる前に JSON へ保存してください。
- 職員名や実際のシフトデータを公開リポジトリへ追加しないでください。
- `.openai/hosting.json` は既存サイトの識別情報を含むため、新しいサイトとして公開する場合はそのまま流用しないでください。
